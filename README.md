# 词盒 · 遗忘曲线背单词

一个单文件网页版背单词工具，按艾宾浩斯遗忘曲线的间隔自动安排复习。不需要服务器、不需要账号、不联网也能背，所有进度存在浏览器本地。

## 功能

- **内置词库 1485 词**：CET6 词库 1347 词、考研高频 79 词、CET4 基础 59 词
- **自建词库**：粘贴导入，格式 `单词|释义`，每行一个，无数量上限
- **间隔排程**：认识升一级（1/2/4/7/15/30/60/120 天），模糊原地保留，不认识打回 1 级并在本轮稍后再现
- **美式音标 + 在线发音**：音标离线内置，发音调用在线单词音频
- **每日新词上限**：10 / 20 / 30 / 50 / 100，或自定义 1–300
- **数据面板**：今日新学与复习量、已掌握词数、未来 7 天复习量预测、连续打卡
- **备份**：导出 / 导入 JSON，换手机或清缓存前记得备份

## 用法

1. 下载 `词盒背单词.html`
2. 用浏览器打开（手机可从文件管理器选择「用浏览器打开」）
3. 浏览器菜单「添加到主屏幕」，即可像 App 一样使用
4. 桌面端也支持：空格翻开释义，`1` 不认识 / `2` 模糊 / `3` 认识

## 数据结构

进度保存在 `localStorage` 的 `cihe_v1` 键下，结构为：

```
{ words: [{ id, w, m, deck, lvl, due, seen, right, wrong, last, gd }],
  settings: { dailyNew, decks },
  log: { "YYYY-MM-DD": { nw, rv, ok, mid, bad } } }
```

`lvl` 为记忆等级 0–8，`due` 为下次复习日期。

## 构建音标（可选）

`tools/` 下是重新生成音标映射的脚本：

```bash
# 先下载开源 IPA 词典到 tools/en_US.txt
python tools/build_ipa.py     # 生成 tools/ipa_map.json
python tools/inject_ipa.py    # 注入到 HTML
```

## 数据来源

- 单词释义由本项目整理，覆盖大学英语四六级与考研常见词汇
- 音标来自开源项目 [ipa-dict](https://github.com/open-dict-data/ipa-dict)（英文数据源自 Wiktionary），遵循其原始授权

## 说明

- 本工具只做词库整理与排程，不包含任何商业词书（如星火、墨墨等）的原始内容；
- 进度只存在本地，清除浏览器数据会丢失，请定期导出备份。
